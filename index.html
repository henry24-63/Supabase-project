How to use your Master Key

Send requests directly to your Vercel Proxy endpoint. You can either specify x-project-name for a specific account, or omit it to query ALL accounts in parallel!

cURL Request Example 
curl -X POST https://proxproject.vercel.app/api/proxy \
  -H "Authorization: Bearer omni_live_master_default_2026" \
  -H "x-project-name: all" \
  -H "Content-Type: application/json" \
  -d '{"action": "query", "path": "users"}'
